# La page nie quatre fois les autres raisons de venir

Remarque de William, 2026-09-09 : *« il y a un manque de cohérence entre les
3 raisons de commencer, centré sur le combat, et autres disciplines disponibles
qui ne sont pas que la self-défense. Et globalement tout l'aspect simplement
coach sportif avec les arts martiaux comme catalyseur est oublié du site. »*

## Le constat

La page ne se contente pas de mettre la sécurité en avant : elle **ferme** les
autres portes, en toutes lettres, à quatre endroits.

```
  ┌─ HERO ──────────────────────────────────────────────────────────────┐
  │  Vous n'avez pas à subir.                                           │
  │  « Coach particulier de Krav Maga et de self-défense. »             │
  │                              ▲ l'identité exclut le coach sportif   │
  └─────────────────────────────────────────────────────────────────────┘

  ┌─ SITUATIONS ────────────────────────────────────────────────────────┐
  │  Trois raisons de commencer                                         │
  │  « On ne vient pas apprendre à se battre. On vient pour arrêter      │
  │    d'avoir peur de quelque chose de précis. »                       │
  │      ▲ deux négations : ni la pratique, ni la forme                 │
  │  01 Je ne me sens pas en sécurité                                   │
  │  02 Mon enfant est harcelé          ← trois PEURS, aucun autre motif│
  │  03 Mon équipe est exposée                                          │
  └─────────────────────────────────────────────────────────────────────┘

  ┌─ DISCIPLINES ───────────────────────────────────────────────────────┐
  │  « Quatre AUTRES disciplines, SI le Krav Maga n'est pas             │
  │     ce que vous cherchez »                                          │
  │      ▲ l'offre est posée en plan B, dans son propre titre           │
  └─────────────────────────────────────────────────────────────────────┘

  ┌─ BIENFAITS ─────────────────────────────────────────────────────────┐
  │  Sept effets, séance après séance                                   │
  │  « La self-défense en est la porte d'entrée. Ce qui suit vient      │
  │    avec, QUE VOUS LE CHERCHIEZ OU NON. »                            │
  │      ▲ on refuse que ce soit une raison de venir                    │
  └─────────────────────────────────────────────────────────────────────┘
```

**Le site contredit son propre coach.** Sur `/le-coach/`, page 2, David écrit :

> « Développement personnel, sport et pédagogie ont toujours été mes plus
> grandes passions. […] En me perfectionnant dans les techniques de combat,
> j'ai beaucoup appris sur mes capacités et mes limites. Je vous propose de
> vous transmettre ce **savoir-être** pour profiter au maximum de votre
> savoir-vivre. »

Ce n'est pas un texte inventé : c'est sa parole, reprise de son ancien site. Le
positionnement « arts martiaux comme catalyseur » **existe déjà sur le site** —
mais il est à un clic, derrière une page que personne n'ouvre avant d'avoir
décidé.

## La structure proposée

Deux portes, la sécurité garde la tête. Rien à construire : les deux sections
qui portent le second motif **existent déjà** — elles sont mal titrées, mal
enchaînées, et leurs chapeaux les désavouent.

```
  AVANT                                  APRÈS
  ─────────────────────────────────      ─────────────────────────────────
  hero        Krav Maga + self-déf.  →   hero        + « et coach sportif »
  situations  3 peurs                →   situations  3 peurs, chapeau ouvert
  formules    2 façons de travailler →   formules    inchangé
  disciplines « si le Krav Maga      →   disciplines TITRE QUI NOMME L'OFFRE
              n'est pas ce que                       + le savoir-être de David
              vous cherchez »
```

## L'alternance des fonds après permutation

Les sections alternent `clair` / `pierre`. Permuter `deroule` et `bienfaits`
oblige à réaffecter deux classes, sinon deux fonds identiques se touchent :

```
  AVANT   situations(clair) formules(PIERRE) disciplines(clair)
          deroule(PIERRE)   bienfaits(clair) fond(PIERRE) …

  APRÈS   situations(clair) formules(PIERRE) disciplines(clair)
          bienfaits(PIERRE) deroule(clair)   fond(PIERRE) …
                  ▲ classes échangées, l'alternance tient
```

## L'écart entre ce croquis et ce qui a été posé

Ce croquis proposait **cinq cartes**, le Krav Maga réintégré à sa propre liste.
La grille `.princ` est figée à `repeat(4,1fr)` et sert **aussi** `/la-discipline/`
pour ses quatre principes : une cinquième carte y aurait laissé une orpheline sur
une deuxième ligne, ou exigé une variante CSS plus une colonne vide sur l'autre
page.

Posé à la place : le titre nomme les quatre — **« Karaté, boxe anglaise, boxe
thaï, MMA »** — et le chapeau nomme le cinquième : *« Le Krav Maga n'est pas la
seule discipline enseignée. »* L'omission est réparée, sans dette CSS.

est trop timide et le hero lui-même devrait basculer. Question à ajouter à
